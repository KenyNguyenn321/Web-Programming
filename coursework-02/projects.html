Aurora Command Application

I contributed to the Aurora Command App, a production application used by fleet operations teams to monitor and manage autonomous trucks. I worked across the full stack using React, TypeScript, GraphQL, Go, and gRPC to build features and improve operational workflows.

This experience strengthened my understanding of production software, testing, code review, and collaboration across engineering teams.

Secure Database Credential Onboarding

At American Express, I worked on database credential onboarding for Oracle workloads hosted on an internal cloud platform. The project used Go, TypeScript, HashiCorp Vault, Couchbase, and HTTP APIs to support secure access to dynamic credentials.

The solution reduced manual credential handling and helped make the onboarding process faster and more consistent for application teams.

AWS Patch Management Automation

At Regions Bank, I helped automate patch management across AWS accounts and organizational units. The project used Python, AWS Step Functions, CloudFormation, and GitHub Actions to coordinate infrastructure tasks.

This automation improved processing efficiency and reduced the amount of manual work required to manage cloud resources across multiple environments.
