UG 01: Forensic Cascade Reconstruction

Three conflicting declarations target the paragraph through an element selector, a class selector, and an ID selector.

Prediction

The #cascade-target declaration should win because an ID selector has greater specificity. I predict the computed color will be rgb(106, 27, 154).

UG 02: Pixel Budget Under Constraint

Both panels produce an outer width of exactly 420 pixels at a 900-pixel viewport without declaring width: 420px.

Content-Box Version

Content-Box Panel

Padding and borders are added outside the declared content width. 

.content-box-demo {
    box-sizing: content-box;
    width: 40vw;
    padding: 27px;
    border: 3px solid #176b4d;
}

360px + 54px padding + 6px border = 420px

Border-Box Version

Border-Box Panel

Padding and borders are included inside the declared width. 

.border-box-demo {
    box-sizing: border-box;
    width: calc(40vw + 60px);
    padding: 27px;
    border: 3px solid #176b4d;
}

40vw at 900px = 360px
360px + 60px = 420px

UG 03: Breakpoint Failure Study

The three-card layout first failed my tested layout condition at an odd-numbered width of 775 pixels.

Structure

Semantic HTML organizes the content.

Presentation

External CSS controls the design.

Testing

Responsive testing finds failures.

Three 220-pixel columns and two 18-pixel gaps require at least 696 pixels of internal space. At a 775-pixel viewport, the surrounding margins and padding left less than 696 pixels for the grid. 

@media (max-width: 775px) {
    .breakpoint-demo {
        grid-template-columns: 1fr;
    }

    .breakpoint-card {
        min-width: 0;
    }
}

The repair removed the overflow at 775 pixels and preserved the three-column layout at 1201 pixels.

GR 01: Refactor With a Measured Tradeoff

Evaluation Criteria Defined Before Coding

  1. Readability: A reader should understand the purpose of a rule from its class name.
  2. Reuse: A style should be reusable without duplicating declarations.
  3. Editing effort: A visual change should require editing as few locations as possible.

Final Choice

I selected the component-oriented architecture because names such as .component-schedule and .schedule-course describe the role of each element. It requires fewer classes in the HTML and keeps related timetable declarations together.

One disadvantage is that the component rules are less reusable outside the timetable. A utility class such as .u-center could be reused anywhere, while .schedule-course is tied to one component.

Naming Decision

I chose .schedule-course because it describes the element's purpose instead of its current color or appearance. The class can keep the same name if the visual design changes later.

GR 02: CSS Performance Experiment

Falsifiable Claim

For 1,000 visually equivalent boxes, the Grid implementation will have a lower median creation and forced layout time than the Flexbox implementation across five trials in the same browser environment.

Controlled Variables

  • Same computer and browser
  • Same viewport size
  • Same number of boxes
  • Same box dimensions and content
  • Same colors, borders, and container width
  • Alternating test order to reduce order bias

Implementations

.perf-flex {
    display: flex;
    flex-wrap: wrap;
}

.perf-grid {
    display: grid;
    grid-template-columns: repeat(10, 60px);
}

Select Run Five Trials to begin.

Interpretation Rule

The claim is supported only if the Grid median is lower than the Flexbox median. The result applies only to this browser, device, test size, and implementation. It does not prove that one layout system is always faster.
