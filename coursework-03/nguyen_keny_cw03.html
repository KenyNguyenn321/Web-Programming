Exercise 1: External Style Sheet

This page links to the external stylesheet styles.css in the document head. The stylesheet applies a dark-red text color, a sans-serif font, and readable line spacing to the body element.

External CSS demonstration

This paragraph inherits its dark-red text color from the body rule in the external stylesheet. 

body {
   color: darkred;
   font-family: Roboto, Arial, sans-serif;
   line-height: 1.6;
}

The stylesheet is connected to this page using the following element: 

<link rel="stylesheet" href="styles.css">

Exercise 2: Debugging CSS

My Debugging Analysis

Finding 1: Missing declaration terminator

Original: color: red

Correction: color: darkred;

A browser can accept the final declaration without a semicolon, but omitting it is fragile because a new declaration added afterward may not parse correctly. The correction adds the terminator and uses a darker red for stronger contrast against the ivory background.

Finding 2: Missing generic font fallback

Original: font-family: "Times New Roman";

Correction: font-family: "Times New Roman", Times, serif;

The original declaration depends on one installed font. Adding fallback fonts allows the browser to use another serif typeface if Times New Roman is unavailable.

Finding 3: All headings use the same size

Original: h1, h2, h3 { font-size: 2.5em; }

Correction: Use separate font sizes for h1, h2, and h3.

Giving every heading the same size removes the visible hierarchy between page titles and subsection headings. Separate sizes make the page structure easier to scan.

Corrected CSS

body {
   font-family: "Times New Roman", Times, serif;
   max-width: 1100px;
   margin: 0 auto;
   padding: 20px;
   text-align: left;
   background: ivory;
   color: darkred;
}

h1 {
   color: #9b0000;
   font-size: 2.5em;
   margin: 20px 0;
}

h2 {
   color: #9b0000;
   font-size: 2em;
   margin: 20px 0;
}

h3 {
   color: #9b0000;
   font-size: 1.5em;
   margin: 20px 0;
}

.container {
   width: 100%;
   padding: 20px;
   box-sizing: border-box;
}

a {
   color: #0000ff;
   text-decoration: underline;
}
