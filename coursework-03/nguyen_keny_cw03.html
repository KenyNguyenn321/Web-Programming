Exercise 2: Debugging CSS

The provided CSS contains three declarations without ending semicolons. Although browsers may accept a missing semicolon on the final declaration in a block, including it makes the code safer and prevents parsing problems when more properties are added.

My Debugging Analysis

Finding 1: Body Text Color

Original declaration: color: red

Corrected declaration: color: red;

The original declaration does not include an ending semicolon. The browser may accept it because it is the final declaration in the body rule, but adding another property afterward could cause that property to be interpreted incorrectly.

Finding 2: Container Box Sizing

Original declaration: box-sizing: border-box

Corrected declaration: box-sizing: border-box;

The box-sizing declaration is missing its ending semicolon. Adding the semicolon clearly separates it from any property that may be added later and preserves the intended box-model behavior.

Finding 3: Link Underline

Original declaration: text-decoration: underline

Corrected declaration: text-decoration: underline;

The final link declaration also omits its semicolon. Adding the terminator makes the declaration complete and keeps future link styles from becoming part of the same declaration.

Corrected CSS

body {
   font-family: "Times New Roman";
   margin-left: 20%;
   margin-right: 20%;
   text-align: justify;
   background: ivory;
   color: red;
}
