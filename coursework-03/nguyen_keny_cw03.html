Exercise 2: Debugging CSS

The provided CSS contains three declarations without ending semicolons. Including the semicolons makes the code safer when additional properties are added.

My Debugging Analysis

Finding 1: Body Text Color

Original: color: red

Correction: color: red;

The semicolon keeps a future property from being joined to the color declaration.

Finding 2: Container Box Sizing

Original: box-sizing: border-box

Correction: box-sizing: border-box;

The semicolon clearly separates the box-sizing property from later declarations.

Finding 3: Link Underline

Original: text-decoration: underline

Correction: text-decoration: underline;

The terminator keeps future link styling declarations separate.

Corrected CSS

body {
   font-family: "Times New Roman";
   margin-left: 20%;
   margin-right: 20%;
   text-align: justify;
   background: ivory;
   color: red;
}

h1,
h2,
h3 {
   color: #ff0000;
   font-size: 2.5em;
   margin: 20px 0 20px 0;
}

.container {
   width: 100%;
   padding: 20px;
   box-sizing: border-box;
}

a {
   color: #0000ff;
   text-decoration: underline;
}
