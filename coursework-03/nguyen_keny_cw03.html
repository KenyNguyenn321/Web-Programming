Exercise 1: External Style Sheet

Exercise 1 requires an external stylesheet that changes the text within the body element to dark red.

External CSS Demonstration

This paragraph inherits the dark-red text color from the body rule inside the external stylesheet.

External CSS

Exercise 2: Debugging CSS

The provided CSS contains three declarations without ending semicolons. Although browsers may accept a missing semicolon on the final declaration in a block, including it makes the code safer when additional properties are added.

My Debugging Analysis

Finding 1: Body Text Color

Original declaration: color: red

Corrected declaration: color: red;

The original declaration does not include an ending semicolon. Adding the terminator prevents a later property from being parsed incorrectly.

Finding 2: Container Box Sizing

Original declaration: box-sizing: border-box

Corrected declaration: box-sizing: border-box;

Adding the semicolon clearly separates the box-sizing declaration from any property added after it.

Finding 3: Link Underline

Original declaration: text-decoration: underline

Corrected declaration: text-decoration: underline;

The final link declaration also needs a terminator so future declarations remain separate.

Corrected CSS

body {
   font-family: "Times New Roman";
   margin-left: 20%;
   margin-right: 20%;
   text-align: justify;
   background: ivory;
   color: red;
}

h1,
h2,
h3 {
   color: #ff0000;
   font-size: 2.5em;
   margin: 20px 0 20px 0;
}

.container {
   width: 100%;
   padding: 20px;
   box-sizing: border-box;
}

a {
   color: #0000ff;
   text-decoration: underline;
}
