Scene Concept
One connected Halloween story combining a haunted town square, midnight graveyard, and broomstick ride.

Completed Requirements

  • Three distinct CSS-driven chapters
  • HTML and CSS only
  • No JavaScript
  • CSS variables using the required color palette
  • Responsive Grid and Flexbox layouts
  • Human activity and animated characters
  • Black cats, bats, an owl, and a crow
  • Fog, drifting clouds, lightning, and moonlight
  • Moving hearse, broomstick, and hay wagon
  • Hover and keyboard interactions
  • Visible keyboard focus indicators
  • Reduced-motion support
