# The Haunted Harvest

The Haunted Harvest is a responsive Halloween experience created for In-Class
Activity 06. The project follows one connected story through three interactive
chapters using only HTML and CSS.

## Student

- Name: Keny Nguyen
- Category: Graduate
- GitHub: @KenyNguyenn321
- Team status: Solo project

## Chapters

1. Haunted Halloween Town Square
2. Midnight Graveyard Stroll
3. Midnight Broomstick Ride

The scenes are connected through CSS `:target` navigation. No JavaScript is
used.

## Required Elements

The project includes:

- Trick-or-treaters and a storyteller
- Black cats, bats, an owl, and a crow
- Drifting clouds, fog, lightning, wind, and moonlight
- Walking, flying, flickering, floating, and driving movement
- A moving hearse, broomstick, and hay wagon
- Pumpkins, ghosts, witches, gravestones, and haunted buildings

## CSS Features

- CSS variables
- CSS Grid
- Flexbox
- `:target` scene switching
- `:hover` and `:focus-visible` interactions
- Transforms and transitions
- Multiple `@keyframes` animations
- Mobile-first media queries
- `prefers-reduced-motion`

## Accessibility

The project uses semantic HTML, visible keyboard focus states, readable color
contrast, a skip link, descriptive labels, and reduced-motion support.

The gravestones can be focused using the keyboard. Each focused or hovered
gravestone reveals a ghost.
